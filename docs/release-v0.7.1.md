# v0.7.1：Codex PTC v14 能力连续性修复

本补丁修复 Codex PTC 在 AWS/API/远程环境任务和长会话跟进中错误降成只读工具面的行为。

## 主要变化

- AWS、云资源、服务器、测试/生产环境、数据库和凭据驱动的实际查询会直接进入 Code Mode。
- “继续”“开始吧”、错误日志或图片跟进会继承正在进行的修改、验证、恢复或部署能力。
- “重新排版、调整、优化、新增、添加、接入”等表达现在会被识别为修改任务。
- 明确的“只读取/只解释、不修改”仍走低 token 原生工具面。
- Code Mode 不再要求用户启用 `exec_command`，并禁止通过 `read` 暴露凭据文件内容。
- 远程只读查询以及已经明确点名的部署/发布不再要求重复确认。

## 验证

- 29/29 项确定性测试通过。
- 三条 `gpt-5.6-sol Low` 无副作用 DSH 工具面检查均得到 `run_code`，工具调用为 0。
- 测试使用虚构凭据路径，没有读取文件、联网或调用 AWS。

完整日志分析、根因、修复边界和验证方法见 [v14 回归报告](https://github.com/xiaosu19/dsh-codex-mode/blob/main/docs/regression-v14-2026-08-25.md)。
