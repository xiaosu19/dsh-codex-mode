# v0.7.2：Codex PTC v15 通用 Agent 能力路由

本版本取消按业务、云厂商或内容类型枚举能力的方向，改为“明确快路径 + 未知任务能力保底”。

## 主要变化

- 只有可证明的直接回答、本地只读、仓库搜索和 Web 调研进入精简原生工具面。
- 所有未知、含糊或可能需要执行的任务默认保留任务级 `run_code` SDK。
- 实际查询、获取、调用、连接、同步和数据处理不依赖目标名称。
- 陌生行业、内部系统、内容形态和架构任务无需先补关键词。
- 独立知识问题仍可降回低 token 原生模式，连续实施不会丢失能力。

## 验证

- 30/30 项确定性测试通过。
- `gpt-5.6-sol Low` 三回合无副作用实测得到 `run_code → read → run_code`。
- 三回合工具调用均为 0；没有读取文件、联网或接触真实业务数据。

完整设计边界和验证结果见 [v15 回归报告](https://github.com/xiaosu19/dsh-codex-mode/blob/main/docs/regression-v15-2026-08-25.md)。
